# سایت و پنل یکپارچه دیزاینستون با PHP و MySQL

این شاخه زیرساخت دیتابیس، API و پنل فارسی امن را اضافه می‌کند و نسخه PHP سایت را به همان API وصل می‌کند. GitHub Pages با پیش‌فرض استاتیک و داده js/projects.js مستقل باقی می‌ماند.

## رفتار نهایی

- پنل: تنها یک مدیر، ورود/خروج، CSRF و محدودیت ورود؛ CRUD نمونه‌کار و دسته، ترتیب و انتشار، بایگانی/بازیابی، آپلود امن و تماس.
- سایت PHP: همان index.html و ساخت کارت، با منبع داده API؛ دسته‌ها و تماس پویا، مسیر درست تصاویر اولیه و جدید و حفظ گالری بسته در ورود.
- حالت استاتیک: بدون درخواست API و بدون نیاز به PHP/MySQL؛ حالت پیش‌فرض site-config.js تغییر نکرده است.
- خطا یا timeout در هر API: گالری خالی، تماس غیرقابل‌اتکا غیرفعال و تلاش دوباره؛ هیچ fallback یا cache استاتیک در حالت API نیست. پاسخ موفق خالی نیز خالی می‌ماند.
- داده‌های API با textContent/DOM امن ساخته و شماره و مسیر تصویر پیش از استفاده اعتبارسنجی می‌شوند. CSS و تصاویر اولیه و فایل داده استاتیک تغییر نکرده‌اند.
- ورودی PHP همان HTML را می‌خواند؛ دارایی‌ها از gateway محدود خارج از document root سرو می‌شوند و storage فقط از media.php با بررسی انتشار ارائه می‌شود. روتر توسعه مسیر ناموجود را صریحاً 404 می‌کند.

## اجرا و استقرار

راهنمای یکپارچه ویندوز در SETUP-WINDOWS.md شامل نصب، schema/migration، حساب دیتابیس، Seed، مدیر و اجرای سایت و پنل است. راهنمای هاست در DEPLOYMENT.md است. فاز چهارم migration جدید ندارد؛ نصب تازه از schema و ارتقا از migrationهای 002/003 متناسب با نسخه استفاده می‌کند.

document root فقط backend/public، تنظیمات و storage خصوصی، و HTTPS تولید الزامی‌اند. حالت فعلی برای سایت و Backend روی یک origin و ریشه دامنه طراحی شده؛ CORS عمومی یا نصب خودکار زیرپوشه اضافه نشده است. در انتشار Pages با Jekyll، backend حذف می‌شود؛ artifact سفارشی باید فقط index.html/css/js/assets را شامل شود.

## اعتبارسنجی

- تست‌های سه فاز پیشین روی PHP 8.4 / MySQL 8.4 / GD موفق بودند.
- تست Node.js برای منبع داده، URLها، شماره، timeout، پاسخ خالی و نبود fallback موفق بود.
- تست Chromium با پنل و MySQL واقعی: ۲۲ نمونه‌کار، هفت دسته، افزودن عکس و دسته، باکس تماس، تغییر شماره، انتشار/بایگانی/بازیابی، تصاویر قدیم و جدید و کلیدهای پنجره تصویر موفق بود.
- موبایل/دسکتاپ، منوی موبایل، کارت‌های اجاره، خطای شبکه/۵۰۳ و پاسخ خالی، XSS و مسیرهای خصوصی بررسی شدند.
- artifact استاتیک در زیرمسیر مشابه GitHub Pages، بدون هیچ درخواست API، کار کرد. انتشار واقعی Pages، ویندوز و TLS/Apache/Nginx تولید در این محیط اجرا نشده‌اند.

پس از تغییر پنل، صفحه باز سایت باید تازه شود؛ polling اضافه نشده است. بازیابی رمز و رابط تاریخچه رسانه هنوز وجود ندارند. ادغام فقط پس از تأیید مالک انجام شود.

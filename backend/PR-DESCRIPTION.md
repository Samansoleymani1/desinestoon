# زیرساخت PHP و MySQL و API فقط‌خواندنی دیزاینستون

سایت فعلی داده‌های گالری را از JavaScript ثابت می‌خواند. این تغییر زیرساخت مستقل PHP/PDO و MySQL را برای مدیریت آینده اضافه می‌کند؛ فایل‌های HTML، JavaScript، CSS و تصاویر فعلی تغییر نکرده‌اند و سایت هنوز به API وصل نیست.

- پنج جدول با روابط خارجی و ایندکس‌ها؛ ورود ۷ دسته و ۲۲ نمونه‌کار از داده واقعی مخزن.
- Seed تراکنشی و بدون بازنویسی رکورد موجود؛ بدون مدیر یا رمز پیش‌فرض.
- دو API عمومی GET برای دسته‌ها و نمونه‌کارهای منتشرشده، با حفظ قالب داده فعلی.
- تنظیمات محیطی خارج از مسیر عمومی، راهنمای ویندوز و جداسازی Backend از خروجی استاندارد Pages.
- سقف آپلود آینده ۱۰ مگابایت است؛ پنل، ورود و آپلود در این فاز وجود ندارند.

اعتبارسنجی روی PHP 8.4 و MySQL 8.4 در Docker انجام شد: ساخت واقعی دیتابیس، تطابق تمام داده‌ها، Seed تکراری، حفظ ویرایش مدیر، فیلتر انتشار، روابط خارجی، پاسخ HTTP، رد روش‌های نوشتن، عدم دسترسی به فایل‌های خصوصی و خطای امن ۵۰۳ همگی موفق بودند. بررسی نحوی هفت فایل PHP و آزمون منبع Node.js نیز موفق بودند.

قبل از ادغام، روش انتشار واقعی Pages بررسی شود: `_config.yml` برای ساخت استاندارد Jekyll پوشه Backend را حذف می‌کند؛ در انتشار سفارشی Actions فقط فایل‌های عمومی سایت باید وارد artifact شوند. انتشار واقعی Pages و اجرای ویندوز در این محیط آزمایش نشده‌اند.

درخواست ادغام خودکار وجود ندارد؛ ادغام فقط پس از تأیید مالک انجام شود.

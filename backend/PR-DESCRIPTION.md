# زیرساخت و پنل مدیریت فارسی دیزاینستون — فاز اول و دوم

سایت استاتیک فعلی بدون تغییر باقی می‌ماند. این شاخه Backend مستقل PHP/PDO/MySQL، API عمومی فقط‌خواندنی و پنل فارسی برای مدیریت آینده را اضافه می‌کند. HTML، JavaScript، CSS و تصاویر سایت اصلی تغییر نکرده‌اند.

## پیاده‌سازی

- فاز اول: جداول محتوا، Seed هفت دسته و ۲۲ نمونه‌کار واقعی بدون بازنویسی، و API عمومی سازگار با داده فعلی.
- فاز دوم: ورود و خروج، داشبورد و فهرست نمونه‌کار/دسته؛ فرم‌های افزودن، ویرایش و تماس فقط پیش‌نمایش غیرفعال‌اند.
- حساب مدیر تنها با CLI و ورودی مخفی ساخته می‌شود؛ هیچ رمز پیش‌فرض یا ثبت‌نام عمومی وجود ندارد. قید یکتای دیتابیس فقط یک مدیر را مجاز می‌کند.
- نشست، CSRF، محدودیت تراکنشی تلاش ورود، انقضای نشست، بررسی مدیر فعال، escaping و پاسخ خطای عمومی اعمال شده‌اند.
- فایل‌های خصوصی بیرون document root هستند؛ Backend از خروجی استاندارد Jekyll برای Pages حذف شده است. در Actions سفارشی artifact باید فقط فایل‌های عمومی سایت را شامل شود.

## استقرار

روی دیتابیس موجود فاز اول، migration یک‌باره `002_admin_security.sql` لازم است؛ نصب تازه از schema به‌روز استفاده می‌کند. مجوزهای وب و CLI باید مطابق ADMIN.md جدا شوند. HTTPS برای استقرار اجباری است و تنها اجرای لوپ‌بک توسعه استثنا دارد. راهنمای ویندوز، ساخت حساب با PowerShell و تنظیم reverse proxy در ADMIN.md آمده است.

## اعتبارسنجی

آزمون منبع و یکپارچه فاز اول، تست‌های احراز هویت/CSRF/محدودیت ورود/تک‌مدیر/نشست/XSS و بررسی نحوی PHP روی PHP 8.4 و MySQL 8.4 در Docker انجام شدند. migration روی ساختار واقعی کامیت 35550dd با حفظ ۲۲ نمونه‌کار و هفت دسته اجرا شد. بررسی مرورگر Chromium برای نمایش فارسی در عرض‌های ۱۲۸۰ و ۳۹۰ پیکسل، فرم‌های غیرفعال و خروج نیز موفق بود. اجرای ویندوز و استقرار HTTPS/Pages واقعی در این محیط آزمایش نشده‌اند.

## باقی‌مانده

CRUD محتوا و دسته، ذخیره تماس، آپلود امن حداکثر ۱۰ مگابایت، بازیابی رمز و اتصال سایت به API مربوط به فاز سوم‌اند. ادغام فقط پس از تأیید مالک انجام شود.
